# Axb-Optimus Site

Public GitHub Pages site for the **Axb-Optimus** Optimus-class humanoid.

## Live site

After enabling Pages (Settings → Pages → Source: Deploy from branch `main` / root):

**https://fitzyracing1.github.io/axb-optimus-site/**

## Source

- Private code repo: [fitzyracing1/axb-optimus](https://github.com/fitzyracing1/axb-optimus)
- This repo is public and contains only the static website.

## Enable GitHub Pages

1. Open https://github.com/fitzyracing1/axb-optimus-site/settings/pages
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**
3. Branch: `main` · Folder: `/ (root)`
4. Save

The site will be live in about a minute.
