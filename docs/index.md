# Axb-Optimus Site

This repo is the static GitHub Pages site for the Axb-Optimus humanoid. It contains no build step and no code beyond the page itself.

| File | Role |
|---|---|
| `index.html` | page |
| `css/style.css` | styles |
| `js/main.js` | page script |

Preview it locally with `python3 -m http.server`, then open `http://localhost:8000/`. The live URL is https://fitzyracing1.github.io/axb-optimus-site/ once Pages is enabled from `main` / root. The code lives in [axb-optimus](https://github.com/fitzyracing1/axb-optimus).
