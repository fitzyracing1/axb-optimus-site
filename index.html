Predictive-echo cycle

The robot never receives obstacle geometry. It only ever holds an acoustic hypothesis updated after it has already acted.

Restart with sound card restart

Two paths. Both always restart the virtual sound card.

Automatic — every echo hit
OptimusEars.listen(...)
  → sound.restart()     # always
  → skill Ears.listen()
Explicit — full system restart
bot.restart()
  → sound.restart()     # always
  → reset body / mission
  → new telemetry session

What you can do

bot.run(max_cycles=20) Full mission loop
bot.step() Single predictive-echo cycle
bot.restart() Full restart + sound card
bot.wait_and_see(topic) Language mode (still restarts sound)
bot.body / bot.imu Live pose, joints, battery, orientation
bot.mission Custom waypoints & patrol
